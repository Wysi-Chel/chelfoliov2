# Chel portfolio

A dependency-free, responsive portfolio built from the supplied homepage reference and visual moodboard. The interior pages use a shared dark editorial system with glass panels, orbital graphics, star motion, filters, a command palette, and an image lightbox.

## Pages

- `index.html` — landing page with the integrated About, practice, skills, and education sections
- `about.html` — standalone profile route retained for compatibility
- `work.html` — career timeline and disciplines
- `projects.html` — interactive constellation and twelve-project archive, including image-generation and apparel-design portfolios
- `gallery.html` — filterable 13-image photography archive

## Run locally

Open `http://localhost/chelfoliov2/` while XAMPP Apache is running, or open `index.html` directly in a browser.

The site uses the supplied portrait in `assets/chel-portrait.png`. Content and mirrored portfolio assets were sourced from `chelgadores.tech` on July 16, 2026. The shared footer follows the live site's compact copyright-and-icon pattern. The star field and interface are rendered as real HTML, CSS, SVG, and canvas elements; no build step is required.
